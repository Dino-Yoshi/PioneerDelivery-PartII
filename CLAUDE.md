## Agent skills

Issues live in GitHub Issues on Dino-Yoshi/PioneerDelivery-PartII, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Default labels: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.
